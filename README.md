# AI Email Assistant for a Dental Clinic

An AI-powered email automation project built with n8n to help a dental clinic automate email handling and responses.

## Project Overview

This project demonstrates how AI and workflow automation can assist with dental clinic email communication. It uses an n8n workflow and an AI Agent to process incoming emails and generate relevant responses.

## Key Features

- Automated email workflow using n8n
- AI Agent for processing email content
- Gmail integration for email communication
- Automated email response generation

## Tools & Technologies

- n8n
- AI Agent
- Gmail
- Large Language Model (LLM)
